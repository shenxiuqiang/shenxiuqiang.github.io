**DIDMail** 是基于去中心化身份（DID）端到端加密解密去中心化的邮箱服务，为用户提供安全、私密、自主可控的邮件通信服务。

## 核心概念

### 去中心化身份（DID）

DID（Decentralized Identifiers）是 W3C 制定的去中心化标识符标准，遵循 [DID 1.1 规范](https://www.w3.org/TR/did-1.1/)。DIDMail 基于 ArcBlock 区块链平台，采用 [DID:ABT 协议规范](https://arcblock.github.io/abt-did-spec/)，为用户提供去中心化的身份管理。

### 端到端加密

与传统邮件服务不同，DIDMail 采用端到端加密技术，确保邮件内容在传输和存储过程中始终处于加密状态，只有收件人能够解密查看。

## 去中心化

DIDMail 服务节点基于ArcBlock Blocklet 技术构建，实现服务的去中心化：

### [DIDMail Server（服务端）](https://store.blocklet.dev/blocklets/z2qa8AzjBYRmQoPw43sNDvY1XQggR4PUg8eAs)

- **技术基础**：基于 ArcBlock Blocklet 技术构建
- **部署方式**：支持无许可部署，用户可通过 Blocklet Store 一键部署到 ArcBlock 云服务，或自行部署到 Blocklet Server
- **核心功能**：
- 
  - 提供加密邮件存储服务
  - 基于 NFT 的个性化信封市场
  - 基于 NFT 的个性化名片模板市场
  - 基于 NFT 质押实现服务发现保障服务稳定
  - 基于链上交易的邮件投递通知
  - 基于ABT代币实时结算

### [DIDMail Chrome Extension（客户端）](https://chromewebstore.google.com/detail/didmail/iaohpoefeikknejigaaifnajlbkdhlhi)

- **身份管理**：支持导入、生成 DID 账户
- **密钥管理**：安全存储和管理用户私钥
- **加密解密**：对邮件内容进行本地加密和解密
- **用户界面**：提供直观的邮件收发、联系人管理

## 核心特性

### 1. 去中心化

与传统邮件服务不同，DIDMail 的账户与服务并非绑定关系。用户可以在发送邮件时自由选择不同的 DIDMail Server 节点，实现真正的去中心化。

### 2. 个性化 NFT 信封

用户可以选择个性化的 NFT 信封模板，为每封邮件增添独特的视觉标识，提升邮件的美观性和个性化体验；基于付费信封为DIDMail Server 节点持续运营提供保障。

### 3. 加密名片系统

支持基于 NFT 的个性化名片模板，用户可以向联系人发送加密的数字名片，实现安全的信息交换，让邮箱具有社交属性。

### 4. 自主可控

用户完全掌控自己的身份信息和私钥，无需依赖中心化服务提供商，实现真正的数据主权。

## 技术优势

- **安全性**：端到端加密确保邮件内容安全
- **隐私性**：去中心化架构保护用户隐私
- **可扩展性**：基于区块链的分布式架构
- **互操作性**：遵循 W3C DID 标准
- **用户体验**：现代化的浏览器扩展界面

## 应用场景

- **企业通信**：为企业和组织提供安全的内部通信
- **个人隐私**：保护个人邮件的隐私和安全
- **跨境通信**：无需担心不同国家的邮件服务限制
- **数字身份**：作为去中心化数字身份的一部分
