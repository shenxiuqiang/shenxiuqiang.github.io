# **打造摄影与 Web3 的示范性 DApp**

---

## 背景：摄影师的线上生存困境

无论是专业摄影师还是业余爱好者，如今都面临类似的问题：

- **作品曝光有限**：社交平台算法分发限制，优秀作品难以被更多用户发现。
- **客户获取困难**：缺少一个可信、标准化的平台帮助摄影师展示、接单、约拍。
- **权益保护不足**：摄影作品和肖像权缺乏透明的使用和收益保障机制。

传统的摄影师平台更多是中心化的“中介”，摄影师对平台规则没有话语权，收入也被过度抽成。

---

## 产品介绍：GLofter

**GLofter（阁楼摄影）** 是一个基于 **ArcBlock 技术** 的去中心化应用，旨在帮助摄影师和摄影机构搭建属于自己的线上工作室，进行作品展示、客户获取和约拍撮合。

名字来源：

- **Global Local Lofter** —— 全球化 + 本地化 + 摄影师精神
- **阁楼摄影** —— 摄影师在“阁楼”里记录人们的故事，延伸到数字世界

---

## 核心功能

1. **GLofter Server（摄影师端 Blocklet 应用）**
2. 
  - 摄影师可一键部署个人工作室：
  - 
    - 个人介绍 &amp; 联系方式
    - 器材、工作室展示
    - 价格设置（按小时 / 项目）
    - 特殊合作模式（例如免费拍摄但保留作品使用权）
  - 创建分类相册，作品即产品，用户可按需求下单。
3. **GLofter Hub（聚合端 Blocklet 应用）**
4. 
  - 聚合多个摄影师工作室，形成一个摄影师市场。
  - Hub 管理者可制定规则（价格分层、审核标准等）。
  - 提供 API 接口，供移动端或第三方调用。
5. **GLofter Mobile（用户端应用）**
6. 
  - 用户可发现并选择不同的 Hub。
  - 浏览摄影师列表、筛选条件、作品与价格。
  - 发起联系或约拍请求，交易基于 DID 保障。

---

## 技术亮点（ArcBlock 驱动）

- **DID 去中心化身份**
- 
  - 摄影师和用户均使用 DID 登录，身份可信，避免虚假账号。
- **Blocklet 应用生态**
- 
  - Server 和 Hub 均为 Blocklet 应用，可由摄影师或第三方自由部署，去中心化分布式生态。
- **Token 经济模型**
- 
  - Hub 收费模式：摄影师申请上线需支付 Token，不同类型摄影师有差异化价格。
  - 收入自动按比例分配给 Hub 运营方与 ArcBlock 开发者，形成可持续生态。

---

## 商业模式

- **摄影师侧**：免费部署 GLofter Server，低成本上手。
- **Hub 侧**：审核摄影师入驻收取费用，形成平台收入。
- **开发者侧**：参与 Hub 或 Server 模块开发可获得分润。
- **用户侧**：按需支付约拍费用，享受更透明可信的服务。

这种模式不仅能吸引摄影师加入，还能驱动第三方开发者自发构建生态。

---

## 战略价值：ArcBlock 的示范性 DApp

GLofter 不仅是一个摄影应用，更是 **ArcBlock 技术对真实行业落地的最佳展示**：

- 将 **DID、Blocklet、Token 经济** 应用到真实的 **摄影行业**
- 吸引摄影师、用户、开发者三方进入 ArcBlock 生态
- 通过实践发现 ArcBlock 在 **内容版权保护、作品上链存证、支付体验** 等方面的不足，反向推动技术完善

这是一个能够真正“跑起来”的项目，不仅能带来用户与收入，还能作为 **ArcBlock 对外展示的样板工程**，证明 Web3 技术如何赋能传统行业。

4. 在实际运营中收集 ArcBlock 技术的改进需求，推动生态优化。

## 结语

GLofter 希望成为一个示范性项目，证明 **ArcBlock 技术不仅能做 DID 登录和链上交互，更能支撑一个可运营、可盈利的真实应用**。

我们相信，通过 GLofter：

- 摄影师获得了更自由的线上平台
- 用户获得了更透明和安全的服务
- ArcBlock 生态获得了一个标杆级的 DApp

我们期待与 ArcBlock 团队、社区开发者、投资人一起，把这个项目做成 **Web3 时代的摄影行业新标准**。
